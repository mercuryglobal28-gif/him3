# Hither — تحديث القنوات الروسية مع فحص تشغيل فعلي

القائمة المرجعية هي `source_playlist.m3u`. لا تُحذف ولا تُعدّل، ولا تُضاف قنوات خارجها افتراضيًا. يحافظ الناتج الكامل على ترتيب القنوات وبيانات EPG.

## ما تغيّر في هذا الإصدار

الفاحص السابق كان يقبل تواقيع بيانات TS/MP4 دون فك فيديو، ويتجاهل ترويسات التشغيل. أصبح الفحص يشترط فك ثلاثة إطارات فيديو بواسطة FFmpeg ضمن مهلة محددة وخروج العملية بنجاح. لا يوجد نجاح احتياطي إذا غابت FFmpeg.

- دعم User-Agent وReferer وOrigin وCookie من EXT VLC/Kodi أو من لاحقة الرابط، وتمريرها إلى الفاحص والناتج والذاكرة المؤقتة.
- استخدام محلل m3u8 وتجربة ما يصل إلى ثلاث جودات بديلة في قوائم HLS الرئيسية، ضمن ميزانية زمنية مشتركة. القوائم ذات الصوت المنفصل تبقى رئيسية للحفاظ على الصوت.
- ترك معالجة المقاطع الحية وخرائط fMP4 والتشفير المدعوم والتحويلات إلى FFmpeg.
- إضافة أسماء روسية بديلة لمطابقة `НТВ` مع `NTV` و`Первый` مع `Channel One` دون تغيير أسماء قائمتك.
- إضافة قائمة الروابط الروسية الخام من iptv-org إلى مصادر البحث السابقة، للحصول على بدائل أكثر للقنوات نفسها.
- فصل الروابط المتحقق منها عن القنوات المحتفظ بها دون تحقق.

تفاصيل مشاريع GitHub التي استُفيد منها وإصداراتها في [REFERENCES.md](REFERENCES.md).

## التشغيل

يتطلب Python 3.10+ وFFmpeg. على Ubuntu/Debian:

```bash
sudo apt-get update
sudo apt-get install -y ffmpeg
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python iptv_generator.py
```

على Windows/macOS، ثبّت FFmpeg وأضفه إلى PATH، أو اضبط `FFMPEG_BINARY` إلى مساره. لا تكتفِ بتثبيت حزمة Python تحمل اسم ffmpeg. GitHub Actions يثبت FFmpeg تلقائيًا ويجري اختبارات تشغيل الفيديو قبل التوليد.

## أي قائمة أستخدم؟

| الملف | المحتوى |
| --- | --- |
| `source_playlist.m3u` | قائمتك الأصلية؛ لا يكتب السكربت إليها |
| `playlist.m3u` | جميع قنواتك بالترتيب؛ البدائل الناجحة أو الرابط الأصلي عند فشل كل البدائل |
| `verified_playlist.m3u` | فقط القنوات التي فُكّت منها إطارات فيديو في آخر تشغيل؛ هذه قائمة تجربة التشغيل |
| `update_report.txt` | حالة كل قناة وأسباب فشل محاولاتها؛ لا يطبع رموز روابطها |
| `working_links.json` | البدائل الناجحة وترويساتها، وتُفحص مجددًا في التشغيل التالي |
| `alltv.m3u8` | الملف السابق كما هو؛ لا يحدّثه هذا السكربت |

وجود القناة في `playlist.m3u` لا يعني أنها تعمل. افحص `verified_playlist.m3u` وعدد `verified_count` في التقرير. عند عدم نجاح أي قناة تُكتب قائمة verified فارغة حتى لا تُعرض نتيجة قديمة باعتبارها نجاحًا جديدًا.

## الإعدادات

| المتغير | الافتراضي | الوظيفة |
| --- | --- | --- |
| `FFMPEG_BINARY` | البحث في PATH | مسار برنامج FFmpeg |
| `PLAYBACK_TIMEOUT` | `20` | ميزانية فحص الرابط وجوداته بالثواني، تشمل تمهيد التحميل |
| `APPEND_NEW_CHANNELS` | `false` | عدم إضافة قنوات خارج قائمتك |
| `KEEP_UNVERIFIED_CHANNELS` | `true` | الاحتفاظ بالقنوات غير العاملة في الناتج الكامل فقط |
| `MAX_WORKERS` | `16` | عدد الفحوص المتوازية؛ خفّضه للأجهزة الضعيفة |
| `MAX_CANDIDATES` | `10` | حد بدائل كل قناة |
| `SOURCES_FILE` | `sources.json` | مصادر البحث |
| `ALIASES_FILE` | `channel_aliases.json` بجوار السكربت | الأسماء البديلة للقنوات الروسية |
| `FILTER_ADULT` | `false` | فلتر تصنيفات اختياري |
| `BLOCKED_DOMAINS` | فارغ | حظر نطاقات اختياري؛ أُزيل الحظر الثابت السابق |

متغير `DEEP_VIDEO_CHECK` القديم لم يعد يعطّل فحص الفيديو؛ أصبح إلزاميًا. يمكن تغيير الملفات عبر `INPUT_PLAYLIST` و`OUTPUT_PLAYLIST` و`VERIFIED_PLAYLIST` و`CACHE_FILE` و`REPORT_FILE`.

## التثبيت من الحزمة

حزمة التحديث تحتوي على الشفرة وملفات إعدادها، ولا تستبدل قائمة المصدر. انسخها فوق المشروع، بما فيها `.github`، ثم ارفع التعديلات وشغّل **Smart IPTV Playlist Update** من Actions. لم تُرفع التعديلات من هذه الجلسة إلى GitHub.

الحزمة الكاملة تحتوي أيضًا على قوائم المستودع الأصلية. قوائمها المولّدة القديمة ليست نتيجة فحص كامل جديد. نتائج العينة الفعلية مرفقة بصورة منفصلة في `verification-sample/`؛ لا تستبدل قائمة المصدر بالعينة.

## حدود النتيجة

فحص الفيديو لا يثبت هوية القناة ولا يضمن عملها من بلد آخر أو بعد انتهاء صلاحية الرابط. قد يكون فيديو شاشة خطأ قابلاً للفك أيضًا. فشل المهلة أو شهادة TLS أو رفض المزود يُسجّل كفشل؛ لا يتحول إلى نجاح بمجرد تشابه بيانات الملف. لا يجدد البرنامج اشتراكات أو رموز وصول، ولا يتجاوز القيود الجغرافية.

ملف المصدر يحتوي على 1611 مدخلًا في اللقطة التي فُحصت؛ لم يُجرَ فحص شامل لها كلها في هذه الجلسة. الاختبارات الآلية تستخدم خادم HTTP محليًا وفيديو حقيقيًا، إضافة إلى اختبار عينة شبكية روسية ودورة توليد لعينة من قائمتك.

## نتيجة عينة التشغيل في 2026-10-30

اجتازت دورة التوليد القنوات الخمس المختارة من القائمة الأصلية: `Первый HD` و`НТВ HD` و`360 новости HD` و`Мир HD` و`Россия 1 HD`. جرى فحص حتى ستة بدائل لكل قناة باستخدام المصدر الروسي الخام، والتحقق بفك إطارات الفيديو. استُخدمت مهلة 16 ثانية للرابط في العينة. المخرجات والتقرير في `verification-sample/`. هذه عينة وليست نتيجة فحص 1611 قناة.
