# Hither — تحديث القنوات الروسية في القائمة الأصلية

المرجع هو `source_playlist.m3u`: نبحث عن روابط بديلة للقنوات الموجودة فيه، دون إضافة قنوات أجنبية أو تغيير ترتيب القنوات. لم يُحذف أو يُعدّل ملف المصدر أو ملف `alltv.m3u8` في هذه النسخة.

## ما تم تصحيحه

- تعطيل إضافة قنوات جديدة افتراضيًا وفي GitHub Actions.
- إعادة جميع مصادر البحث السابقة، وتقديم قوائم روسيا واللغة الروسية وبيلاروسيا وكازاخستان وأوكرانيا في ملف `sources.json`.
- إزالة TDTChannels من المصادر الافتراضية؛ أُضيف سابقًا نتيجة فهم غير دقيق لنطاق المشروع.
- الحفاظ على أسماء القنوات وترتيبها وترويسة القائمة الأصلية، بما فيها رابط EPG.
- الاحتفاظ برابط القناة الأصلي إذا لم ينجح أي بديل. يُسجّل ذلك في `unverified_names` و`retained_unverified`؛ وجود القناة في الناتج لا يعني نجاح فحصها.
- إزالة الحظر الداخلي الثابت لنطاق `plist.link`، وتحويل فلتر التصنيفات إلى خيار معطّل افتراضيًا.
- تحسين المطابقة بين معرفات المزود مثل `chnl-2` ومعرفات الفهارس العامة، وحماية أرقام القنوات وفروق التوقيت من المطابقة الخاطئة.
- فحص البدائل تدريجيًا، وإعادة استخدام نتائج الروابط المكررة، ودعم التعرف على مقاطع fMP4.

## الملفات والحزم

`hither-russian.zip` يحتوي على نسخة المشروع مع قوائم المصدر الأصلية كما كانت في المستودع عند تنزيله. الملفات المولّدة المرفقة هي لقطة المستودع السابقة، وليست نتيجة تشغيل كامل جديد.

`hither-update.zip` يحتوي على الملفات البرمجية المعدلة والجديدة فقط؛ لا يحتوي على قوائم المصدر لأن الغرض منه تحديث الشفرة دون استبدال قوائمك. غياب القائمة من حزمة التحديث لا يعني حذفها من المشروع.

إذا كانت لديك قائمة مصدر أحدث، استخدم حزمة التحديث أو احتفظ بنسختك الأحدث عند فك النسخة الكاملة. هذه التعديلات محلية ولم تُرفع إلى GitHub.

## التشغيل

يتطلب Python 3.10 أو أحدث. من مجلد المشروع:

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python iptv_generator.py
```

المدخل: `source_playlist.m3u`. الناتج: `playlist.m3u`. التقرير: `update_report.txt`. الذاكرة المؤقتة: `working_links.json`. لا يكتب السكربت إلى `source_playlist.m3u` أو `alltv.m3u8`.

بعد رفع التعديلات، شغّل **Smart IPTV Playlist Update** من Actions. يعمل الجدول كل ست ساعات، وتجري الاختبارات قبل التوليد. يُحفظ التقرير كملف Artifact.

## الإعدادات

| المتغير | الافتراضي | الوظيفة |
| --- | --- | --- |
| `APPEND_NEW_CHANNELS` | `false` | لا تُضاف قنوات خارج قائمتك |
| `KEEP_UNVERIFIED_CHANNELS` | `true` | الحفاظ على القنوات الأصلية عند فشل فحص روابطها |
| `FILTER_ADULT` | `false` | عدم استبعاد تصنيفات من القائمة الأصلية |
| `BLOCKED_DOMAINS` | فارغ | حظر اختياري لنطاقات مفصولة بفواصل |
| `SOURCES_FILE` | `sources.json` | قوائم البحث عن بدائل للقنوات نفسها |
| `MAX_WORKERS` | `16` | توازي الفحص |
| `STREAM_TIMEOUT` | `9` | مهلة اتصال وقراءة الشبكة بالثواني |
| `MAX_CANDIDATES` | `10` | أقصى بدائل لكل قناة |
| `FUZZY_THRESHOLD` | `88` | حد تشابه الاسم |
| `MATCH_POOL` | `8` | عدد الأسماء القريبة المرشحة |
| `DEEP_VIDEO_CHECK` | `true` | فحص اختياري للوسائط المباشرة بـ ffprobe |

تبدأ الذاكرة المؤقتة المحسّنة بمفاتيح جديدة لتجنب خلط القنوات المتشابهة. لا تُحفظ الروابط غير المتحقق منها كبدائل ناجحة.

## الاختبارات والحدود

اجتازت النسخة 17 اختبارًا، منها اختبار يحافظ على القائمة الأصلية وترتيبها وترويسة EPG مع تعطل أحد الروابط ووجود قناة أجنبية في مصدر البحث. لم يُجرَ تشغيل شبكي شامل لكل القنوات الروسية في هذه النسخة.

التحسينات قائمة على قواعد مطابقة وليست نموذج ذكاء اصطناعي. إزالة الحظر الداخلي لا تلغي القيود الجغرافية أو رموز الدخول المنتهية أو رفض خادم البث. HLS يفحص أول مسار ومقطع؛ DASH والترويسات الخاصة والتشفير ليست مدعومة دعمًا كاملًا.
