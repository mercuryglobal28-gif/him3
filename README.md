# Hither — اكتشاف قنوات IPTV والتحقق منها

يجمع المشروع روابط من قوائم عامة، ويبحث عن بدائل للقنوات الأصلية، ويضيف قنوات جديدة اجتازت الفحص. يعتمد البحث على قواعد مطابقة، وليس على نموذج ذكاء اصطناعي أو خدمة مدفوعة.

## تثبيت حزمة التحديث

انسخ محتويات `hither-update.zip` فوق ملفات المستودع مع الحفاظ على المجلد المخفي `.github`. الحزمة تحتوي على الملفات المعدّلة والجديدة فقط؛ لا تستبدل قوائمك الحالية أو رموز روابطها. ثم ارفع هذه الملفات إلى GitHub وشغّل سير العمل. ملف `hither-update.patch` بديل لمن يستخدم `git apply`.

## التشغيل

يتطلب Python 3.10 أو أحدث. يُستخدم `ffprobe` اختياريًا لفحص الفيديو في الروابط المباشرة.

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python iptv_generator.py
```

شغّل الأوامر من مجلد المشروع. أدخل قائمتك في `source_playlist.m3u`. النتائج في `playlist.m3u`، والتشخيص في `update_report.txt`، والذاكرة المؤقتة في `working_links.json`.

## التغييرات

- إزالة الحظر الثابت لنطاق `plist.link`؛ كل رابط HTTP/HTTPS يخضع للفحص نفسه.
- جعل فلتر التصنيفات اختياريًا، ومعطلًا افتراضيًا.
- السماح بالمطابقة الاسمية عندما يكون المعرّف محليًا مثل `chnl-2`، مع الحفاظ على رفض تعارض المعرّفات العالمية.
- توحيد علامات الجودة والتشكيل العربي وأشكال الألف، وتفادي الخلط بين أرقام القنوات وفروق التوقيت.
- استخدام معرّف القناة في الذاكرة المؤقتة لتقليل خلط القنوات المتشابهة. مفاتيح الذاكرة القديمة لا تُستخدم؛ تُعاد بناؤها بعد تشغيل ناجح.
- تنفيذ إضافة القنوات الجديدة، مع حدّ لعدد القنوات المرشحة الجديدة في كل تشغيل.
- فحص البدائل على مراحل: يتوقف البحث عن بدائل القناة بمجرد نجاح رابط، مع مشاركة نتائج الروابط المكررة.
- التعرف على مقاطع HLS المجزأة بصيغة fMP4، وتصحيح قراءة أسماء القنوات التي تحتوي على فاصلة.
- الاحتفاظ بالقائمة والذاكرة السابقة إذا لم ينجح أي رابط، وكتابة تقرير الفشل رغم ذلك.

## المصادر

تُدار المصادر في `sources.json`؛ أضف عنصرًا يحتوي على `name` و`url` و`enabled` دون تعديل Python.

| المصدر | المرجع |
| --- | --- |
| iptv-org | https://github.com/iptv-org/iptv |
| Free-TV | https://github.com/Free-TV/IPTV |
| TDTChannels، مصدر جديد للقنوات المفتوحة | https://github.com/LaQuay/TDTChannels |

أُزيل تحميل القوائم الفرعية المتداخلة من iptv-org، وأُبقي الفهرس العام لتقليل الطلبات المكررة. تعطّل مصدر لا يمنع معالجة بقية المصادر.

## الإعدادات

| متغير البيئة | الافتراضي | الوظيفة |
| --- | --- | --- |
| `APPEND_NEW_CHANNELS` | `true` | إضافة قنوات من المصادر، بعد القنوات الأصلية |
| `MAX_NEW_CHANNELS` | `200` | حد القنوات الجديدة المرشحة للفحص، وليس عددًا مضمونًا للقنوات الناجحة |
| `BLOCKED_DOMAINS` | فارغ | حظر اختياري، نطاقات مفصولة بفواصل |
| `FILTER_ADULT` | `false` | تفعيل فلتر التصنيفات السابق عند ضبطه إلى `true` |
| `SOURCES_FILE` | `sources.json` | ملف المصادر |
| `MAX_WORKERS` | `16` | التوازي في فحص الروابط |
| `STREAM_TIMEOUT` | `9` | مهلة اتصال وقراءة الشبكة بالثواني |
| `MAX_CANDIDATES` | `10` | أقصى بدائل لكل قناة |
| `FUZZY_THRESHOLD` | `88` | الحد الأدنى لتشابه الاسم |
| `MATCH_POOL` | `8` | عدد الأسماء القريبة التي يجري فحصها |
| `DEEP_VIDEO_CHECK` | `true` | فحص اختياري بـ ffprobe للوسائط المباشرة |

أسماء الملفات قابلة للتغيير عبر `INPUT_PLAYLIST` و`OUTPUT_PLAYLIST` و`CACHE_FILE` و`REPORT_FILE`.

تُختار القنوات الجديدة بترتيب المصادر، وتُستبعد الأسماء/المعرّفات المكررة. رفع الحد يسمح بفحص نطاق أوسع. قوائم المصدر تبقى محفوظة دون تعديل.

## GitHub Actions

بعد رفع الملفات إلى المستودع، شغّل **Smart IPTV Playlist Update** من تبويب Actions. يعمل الجدول كل ست ساعات. تسبق التوليد اختبارات الانحدار، ويُحفظ التقرير كملف Artifact حتى عند فشل التوليد. الملف `alltv.m3u8` ليس ناتج هذا السكربت؛ رابط النتيجة هو `playlist.m3u`.

## حدود الفحص

إزالة الحظر الداخلي لا تزيل القيود الجغرافية أو انتهاء الرموز أو أخطاء 401/403 من خادم البث. نجاح الفحص يثبت استقبال بيانات وسائط وقت التشغيل ومن موقع التنفيذ؛ لا يضمن التشغيل في كل بلد أو كل مشغل. DASH والروابط التي تتطلب ترويسات خاصة أو فك تشفير ليست مدعومة دعمًا كاملًا. فحص HLS يفحص أول مسار ومقطع، ولا يجري اختبار تشغيل طويلًا. لا يُجدّد المشروع اشتراكات أو رموز دخول.
